# Fatal Error + Milspec PDA MCM Text String Patch

### Requirements
- [Milspec PDA 1.18.1 - catspaw](https://www.moddb.com/mods/stalker-anomaly/addons/milspec-pda-for-anomaly-151-152-and-gamma)
- [Fatal Error 1.7.9.5 - ncenka](https://www.moddb.com/mods/stalker-anomaly/addons/fatal-error-by-ncenka)

### Installation:
Install the ZIP from [releases](https://github.com/SBDG-0/crispy_stalker_anomaly/releases) as a separate mod in MO2. 

Enable in Mod Organizer.

#### What it does?
Fixes missing text and rewrites some for the mcm menu.
