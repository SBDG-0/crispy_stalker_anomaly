# Crispy S.T.A.L.K.E.R. Anomaly
This is a place for all my fixes, patches and minimods for [S.T.A.L.K.E.R. Anomaly](https://www.moddb.com/mods/stalker-anomaly) 

Maybe some of these are of use for someone else too.

Use [STALKER-Anomaly-modded-exes](https://github.com/themrdemonized/xray-monolith#stalker-anomaly-modded-exes) for best overall compatibility.

### Installation:
Install the ZIP from [releases](https://github.com/SBDG-0/crispy_stalker_anomaly/releases) as a separate mod in MO2. 

Enable in Mod Organizer.

More detailed instructions and informations can be found in the README of each mods archives.

Summary:
---
### Stealth + Ghillie Rework Compatibility Patch
Compatibility Patch for Stealth v2.31 and Ghillie Rework v1.2
### MCM Remembers Last Tab + Custom Mod Categories Compatibility Patch
Custom Mod Categories v1.1.1 compatibility for MCM Remembers Last Tab v1.2
### Back and Forth Button Position Patch
MCM script for repositioning back and forth buttons
### Custom Mod Categories Dropdown Position Patch
MCM script for repositioning CMC dropdown
### Custom Loading Screen Background meant for Multiplayer
Texture replacement for loading screen background.
### Fatal Error + Milspec PDA MCM Text String Patch
Fixes missing text and rewrites some for the mcm menu.
### Pizza's Ultimate Sight Selection for Anomaly Magnifier MCM Text Patch
Adds missing xml string file for magnifier script
### Sota UI Rework MAS DevKit Ultrawide Patch
Adjusts the layout on the draggable hud editor layout slightly.
